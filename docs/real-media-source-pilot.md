# Real media source pilot

The controlled pilot uses GBIF occurrence media for the governed `Pterois volitans` taxon (GBIF taxon key 2334438). GBIF was selected because its occurrence API provides stable occurrence identities, provider/dataset provenance, exact taxon linkage, image references, and item-level media licenses. The production cap is 25 candidates; the operational pilot should request 10–25.

Only item-level CC0 and CC BY 4.0 media are eligible for training review. CC BY-NC is reference-only for this pilot, CC BY-SA is treated as derivative-restricted pending policy review, and absent/unknown licenses fail closed. Registration or retrieval never constitutes asset approval.

Candidate assessment: GBIF is suitable case-by-case; Wikimedia Commons is promising but requires a separate taxonomy/provenance adapter; direct iNaturalist requires item-by-item licensing and overlap reconciliation; WoRMS-linked media remains reference-oriented until rights and stable retrieval are validated. No search-engine scraping is permitted.

Media is identification material only. It is not jurisdiction occurrence evidence, ecological status, invasiveness, suitability, or anomaly evidence.
