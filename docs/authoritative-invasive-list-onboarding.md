# Authoritative invasive-list onboarding

No authoritative Jamaica invasive-species list is bundled or fabricated by Milestone 16.

When a real list is supplied, register its ecological-status source with jurisdiction scope, version, publication reference, license, acquisition method, and semantics. Hash and preserve the original artifact; explicitly map fields and source categories; run taxonomy, jurisdiction, and semantic reconciliation; then review rows independently. Unknown taxa route to taxonomy review. Regional or global membership cannot silently become jurisdiction status.

Only explicitly approved rows may create ecological assertions through the existing idempotent apply workflow. Conflicts remain visible. Disappearance from a later list does not imply eradication or reversal. Public directories expose only current approved governed assertions, never legacy-unverified values or ingestion candidates.
