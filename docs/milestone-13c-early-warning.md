# Marine early-warning intelligence

An anomaly is a governed signal that an expert-verified observation differs from available baselines and may deserve human attention. It is **not** invasive status, a new species claim, a threat, confirmed range expansion, impact, or a probability.

Eligible observations require valid coordinates, an expert-confirmed or corrected identity, regional taxon governance, jurisdiction ownership, and independent (non-duplicate) evidence. AI-only and reporter-suggested identities cannot activate evaluation. Unknown verified taxa route to taxonomy review.

The composable signals describe occurrence-baseline availability, nearest governed-record distance, temporal coverage, exact jurisdiction/taxon suitability context, and approved ecological-status context. Distance has no default anomaly threshold. Low suitability does not invalidate an observation. Ecological status is context only.

A weak or missing baseline produces `INSUFFICIENT_BASELINE`; it never produces “first record.” `REVIEW_SUGGESTED` is possible only through an explicitly approved, versioned anomaly configuration. Every assessment records deterministic dependency fingerprints and limitations. Changed dependencies produce a new assessment while retaining stale/superseded history.

Scientific disposition is append-only and separate from identity review. Acknowledging or escalating a signal never creates governed occurrence evidence; that requires the existing 12C review workflow. It also creates no taxonomy approval, ecological assertion, dataset applicability, species program, model, or anomaly publication.

Milestone 13D adds a controlled event boundary and jurisdiction-scoped scientific-reviewer grants. Automatic evaluation remains disabled unless an ACTIVE, reviewed jurisdiction × taxon configuration explicitly enables it. There is still no background scheduler. Raw assessments remain institutional and are not exposed on public species pages.
