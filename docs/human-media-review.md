# Human identification-media review

Software may validate provider identity, licensing metadata, attribution, dimensions, decoding, hashes, and possible duplication. It cannot create `APPROVED` scientific review.

The admin workspace provides a focused large preview, provider and license links, governed target, provider taxonomy evidence, attribution, locality/date, technical quality, SHA status, duplicate context, limitations, previous/next navigation, and explicit decisions. Arrow keys navigate and Escape closes the focused view.

Every decision requires a concise governed reference and creates an append-only event. There is no blind bulk approval. License-blocked records may be excluded, but restricted rights are never broadened.
