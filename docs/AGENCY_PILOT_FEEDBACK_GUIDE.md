# External tester feedback guide

Use a short interview after hands-on testing:

- Would this fit work your team currently performs?
- Which part would be useful, and which would not?
- What information was missing during review?
- Which staff role would actually use this?
- Where would this duplicate an existing process or system?
- What would prevent adoption?
- What would make the workflow useful regularly?
- How are sightings received, identified, escalated, and retained today?
- Were any scientific or operational labels misleading?
- Was jurisdiction access understandable?
- Would a controlled pilot be worth continuing? Why?

Record operational/product feedback in the pilot feedback tool. Do not treat feedback as scientific evidence or ecological interpretation.
