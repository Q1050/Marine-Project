# Representative Caribbean identification benchmark

The benchmark label space may contain only accepted species-level taxa approved in the Caribbean `RegionalTaxonRegistry`. Regional recognition means the platform can discuss an identity; it does not establish occurrence, native/non-native/invasive status, or jurisdiction evidence.

Milestone 19 prepared the existing cross-group WoRMS manifest. It did not invent a 20–50 taxon list: one taxon was already governed, four exact species candidates entered human review, and one cnidarian name was blocked because live exact-name resolution was not unique. Acquisition can begin only after explicit taxonomy approval and apply.

Per-taxon acquisition plans bind provider order, bounded target, license-first filtering, technical validation, retry policy, global duplicate checks, existing counts, and a stopping condition. A frozen benchmark binds exact reviewed assets and source-independent group identities.
