# Jurisdiction science boundary

The following identities must remain separate:

- Regional taxon governance: an authoritative taxon is eligible for regional workflows.
- Jurisdiction occurrence evidence: a reviewed record falls within a governed jurisdiction boundary.
- Ecological status: an approved authority explicitly asserts a jurisdiction-specific status.
- Public display: approved current data passes its own display and media governance.
- Identification, suitability, and early warning: each uses independently reviewed prerequisites.

Therefore regional relevance is not presence; presence is not native/non-native/invasive status; list membership is not status unless source semantics say so; and model readiness is not evidence or an anomaly. Missing data is shown as blocked, partial, unknown, or review-required and is never interpreted as absence.
