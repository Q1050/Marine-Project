# Agency pilot demo — 5–8 minutes

1. **Purpose (30 seconds):** Explain that the prototype receives marine sightings and supports jurisdiction-specific operational review. It does not infer invasive status from a sighting.
2. **Jamaica context (45 seconds):** Open Jamaica monitoring and the governed marine-species directory. Show occurrence context without describing it as ecological status.
3. **Submit (60 seconds):** Submit a test sighting with an image and real test location. Show the opaque reference and preliminary-identification notice.
4. **Reviewer workspace (45 seconds):** Sign in with a purpose-created Jamaica reviewer account. Show that only Monitoring Home and Observation Review are available.
5. **Queue and assignment (45 seconds):** Open the queue, claim the unassigned report, and demonstrate the authorized reviewer picker.
6. **Evidence (60 seconds):** Open the report. Distinguish reporter suggestion, AI assistance, and expert decision. Show coordinates, duplicate context, and protected image.
7. **Review (60 seconds):** Confirm or correct the identification. If useful, request more information and explain the opaque reporter response link.
8. **Audit and close (45 seconds):** Show ordered audit events and close the case after a final disposition.
9. **Scientific firewall (45 seconds):** Explain that verification only makes a report eligible for a separate governed evidence review. It does not create scientific evidence or ecological status automatically.
10. **Future direction (30 seconds):** Explain that authoritative source governance supports the invasive directory and that anomaly/early-warning work remains separate and scientifically reviewed.

Use isolated test records. Do not imply that demo actions are real agency activity.
